# Changelog

## 0.1.0

- Per-pen gender targets: set females to keep; males to keep is the slaughter
  limit minus that.
- Villagers slaughter an adult from whichever gender is over its target.
- Pups are ignored until grown, unless `CountPupsTowardTargets` is on.
- Targets are saved with the pen.
- A window beside the pen's slaughter task to set targets and preview the next
  slaughter.
